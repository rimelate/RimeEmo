VRCHAT EXPRESSION EDITOR

RimeEmo

表情をつくる。動きをつなぐ。
アバターの表情づくりを、ひとつのツールで。

さっそく始める

VPM

Creator Companionにリポジトリを追加して、
RimeEmoをインストールできます。

VCCに追加 VCCをインストールしたPCで開いてください。

必要な環境

  • Unity 2022.3
  • VRChat SDK — Avatars
  • Modular Avatar ↗
01

リポジトリを追加

上のボタンを押し、VCCで追加を承認します。

02

プロジェクトに導入

使いたいプロジェクトの管理画面で、RimeEmoを追加します。

03

Unityで開く

Tools → RimeEmo → Openから、表情の編集を始められます。

ALCOM・手動で追加する場合

リポジトリ追加画面に、以下のURLを貼り付けてください。ボタンでVCCが開かない場合も使えます。

RimeEmo by rimelate
