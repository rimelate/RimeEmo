# RimeEmo

Unity 2022.3向けのVRChat表情編集ツールです。静的なAnimationClipの編集、パーツ別の動的Motion、Gesture割り当て、FX生成、Modular Avatar経由の適用までを扱います。

## インストール・更新

[配布ページで「VCCに追加」をクリック](https://rimelate.github.io/RimeEmo/)し、プロジェクト管理画面から **RimeEmo** を追加してください。

ALCOMを使用する場合や手動で登録する場合は、次のVPMリポジトリURLを追加してください。

```text
https://raw.githubusercontent.com/rimelate/RimeEmo/vpm/index.json
```

[更新履歴・ダウンロード](https://github.com/rimelate/RimeEmo/releases)

Unity 2022.3を対象にしています。アバターへの適用にはModular Avatarが必要です。
旧Assets版を利用している場合は、プロジェクトのバックアップを取ってから移行してください。
VPMへの移行ではツールのコードフォルダーだけを置き換え、ローカルの作業データは保持します。

新しい安定版が公開されるとツール内に通知します。`設定`ページから手動確認、
自動確認の有効・無効、VPM URLのコピーができます。自動確認はツールを開いたときだけ行い、更新の適用はVCC / ALCOMで行います。

GitHubと配布ZIPに含めるのはツール本体だけです。
`Working`・`Generated`・`Backup~`、アバターや購入アセット由来のデータは含めません。
配布手順は[Scripts~/README.md](Scripts~/README.md)を参照してください。


## 表示言語

画面右上の`Language / 言語`で、日本語とEnglishを切り替えられます。初期表示はシステム言語が日本語なら日本語、それ以外は英語です。選択はエディター設定に保存され、メイン画面・Gesture設定・部位設定・確認ダイアログに反映されます。言語を切り替えても、編集中の下書き、再生位置、Clip名やShape Key名は変わりません。

## 起動と操作ガイド

Hierarchyのアバター行にある`RimeEmo`ボタンを押すと、そのアバターを指定した状態でツールを開きます。VRChatのAvatar Descriptor、保存済みのRimeEmo設定、またはアバターのAnimatorを目印に表示します。`Tools > RimeEmo > Open`からも開けます。

初回起動時は、言語選択からGesture適用までの操作ガイドを表示します。説明している場所を枠で強調し、次へ・戻るで読み進められます。ガイドはいつでも閉じられ、右上の`？`（使い方）から再表示できます。表示履歴はエディター設定に保存されます。

画面はGoogleのMaterial Design 3に沿った構成です。上部のバーにアバター選択・保存・アバターへの適用・使い方・言語、左のナビゲーションレールに作業の順番どおり「表情を作る」「動きを作る」「Gesture」、下端に「設定」を並べています。レールで選んだページだけを表示するので、別ウィンドウを開いたり閉じたりする必要はありません。「表情を作る」はひとつの表情の調整、「動きを作る」は表情を時間順に並べる作業です。顔メッシュなど使用頻度の低い設定は「設定」ページにまとめています。アバターが未セットアップの間は「設定」ページを表示します。

## 表情を編集する

1. `Tools > RimeEmo > Open`を開き、`Avatar`にScene上のアバタールートを指定します。
2. 初回は左下の`設定`ページで`読込元FX`を確認し、`新規セットアップ`を押します。セットアップ後は自動で表情の編集に移ります。Sceneの現在のBlendShape値をDefault Faceとして保存し、元FXのClipをWorkingへコピーします。設定済みのアバターは指定するだけで読み込まれます。設定済みのアバターで`新規セットアップ`を押すと確認を表示します。新しく作ると、アバターは新しい設定に切り替わり、以前の素材は削除されずに残ります。`読込元FX`はセットアップ時の素材の取り込み元です。セットアップ後に変更すると、FX生成の元だけが切り替わります。
3. 素材一覧でClipを選び、検索と絞り込みでShape Keyを探します。スライダーや数値欄を動かすと、そのClipに含まれていないShape Keyもそのまま追加されます。
4. `表情を作る / Create Expressions`モードでプレビューを確認し、上部の`保存`を押します。プレビューは正面・平行投影が初期状態で、VRChatのViewPositionを参考に構図を決めます。ドラッグで回転、ホイールで拡大・縮小できます。

顔メッシュは名前が`Body`のものを優先します。顔メッシュの選択肢はShape Keyを持つメッシュだけで、Shape Keyの多い順に件数付きで並びます。顔メッシュの選択、部位分類、アバターの再読み込み、未使用データの整理は`設定`ページにまとめています。部位分類はProjectに保存されます。部位設定（「部位とグループ」ウィンドウの部位タブ）では各Shape Keyの部位を日本語の部位名で選べます。手動で指定した部位は`自動に戻す`で自動判定へ戻せます。

部位の自動判定は、大文字・小文字、全角英数字、区切り文字、`eyeBlinkLeft`のような単語の連結、名前の途中にある`L`・`R`に対応します。まぶた・まつ毛・瞳・キャッチライトは左右指定があるものを各目へ、Viseme・顎・舌・歯は口へ分類します。`EyeLook_Left`や`Iris_Left`は視線の方向なので左目には分類しません。左右不明・両側共通のShape Keyは「その他」に残します。自動判定は再読み込み時に更新しますが、部位設定で手動指定したものは維持します。

動的編集では素材にカーソルを合わせて表情を確認でき、外すと現在の再生位置にある作成中のアニメーションへ戻ります。

`×`はカーブそのものを削除し、そのShape KeyはDefault Faceの値に戻ります。値を0にする操作ではありません。`Defaultと同じ値を削除`は全時間でDefault Faceと同じカーブだけを除去します。時間変化のあるカーブは、`0秒の値で固定`を選んだ場合だけ静止値へ変換します。Default値は項目のツールチップでも確認できます。

`新しい表情`は「新しい表情」という名前の空のClipを作成し、名前の欄を選択した状態にします（そのまま名前を入力してEnter）。Clipに入るのは値を動かしたShape Keyだけで、それ以外はプレビューでもFX生成でもDefault Faceの値になります。外部Clipは`素材を追加`を押すと、**このアバターのアニメーションだけ**を一覧から選んで追加できます（検索欄で絞り込めます）。一覧へのドロップも使えます。Project内に複数のアバター（例：MAYOとManuka）があっても、別のアバターの表情は一覧に出ず、ドロップしても取り込みません。判定は顔メッシュのShape Keyの名前で行います。Clipが動かす顔のShape Keyのうち8割以上がこのアバターにあるものだけを、このアバターのものとして扱います。顔メッシュの名前（`Body`など）が同じでも区別でき、同じ素体から改変したアバターどうしはShape Keyの名前が共通なので使えます。セットアップ時の取り込み、タイムラインやGestureの割り当て欄へのドロップでも同じ判定をします。静的モードの`その他`メニューには、複製、Clip書き出し、Defaultと同じ値の削除、この表情から動的アニメーションを作成、表情の削除があります。削除は確認のうえClipをゴミ箱へ移動します（一覧でDeleteキーでも同じ）。Gestureに割り当てている表情を削除すると、その手の形はDefault Faceになります。動きは独自のコピーを使うので影響しません。素材一覧には静的・動的の両方を表示し、各行のラベルで区別します。右端にはGesture設定で割り当てた手の組み合わせを表示します。未割り当ての場合は、元FXから読み取れた条件を「元FX:」付きの参考情報として表示します。Bodyとして設定されている顔メッシュのBlendShapeカーブがないClipは、取り込みと一覧表示から除外します。キーが1つ、または複数でも対象BlendShapeに時間変化がないClipは静的です。イベントや別メッシュの動きは分類に使いません。補間途中に値が動くClipは動的です。

一覧で素材を選び、「表情を編集」「動きを編集」またはダブルクリックで対応する編集画面を開きます。素材の追加だけでは編集中の動きを切り替えません。以前に動的として保存されたClipが静的と判定された場合、静的編集時に独立したコピーを作り、元の動きは保持します。

Shape Keyは1つの一覧に並びます。Clipに含まれていないShape Keyは薄く表示され、Default Faceの値を示します。値を動かすか`+`を押すとClipに追加され、`×`で外せます。Default Faceと同じ値のShape Keyは左端に線を表示します。

絞り込みは3種類を組み合わせて使います。

- **部位**：「すべて・左目・右目・眉・口・その他」のフィルターチップ。左右キーでもチップを移動できます。
- **グループ**：部位の右に並ぶ、自分で作ったまとまり。部位とグループはどちらか1つを選びます。
- **Clipとの関係**：「すべて・含まれる・Defaultと違う・含まれない」。各ボタンに件数を表示します。`Defaultと違う`は値がDefault Faceと違うか、時間で変化するShape Keyだけを表示するので、表情を実際に変えているShape Keyの確認に使えます。既存のClipはDefault Faceと同じ値も多く含むため、この絞り込みが特に役立ちます。
- **検索**：Shape Key名の一部で絞り込みます。

絞り込み中に値を変えたShape Keyは、条件から外れても絞り込みや検索を変えるまで一覧に残ります。編集途中で行が消えることはありません。

`絞り込み`メニューでは、候補から隠すShape Keyを選べます。設定はエディター全体で共有します。

- **区切り用のShape Key**（初期設定で有効）：`-----EyeLook-----`のように、記号の連続で始まる・終わる名前や、文字を含まない名前。
- **VRChat用（vrc.）**：`vrc.`または`vrc_`で始まる、リップシンク・まばたき・視線用の名前。

隠すのはClipに含まれていないShape Keyだけです。含まれているものは常に表示します。隠している件数は一覧の上に表示します。

### グループ

「照れ」「ハイライト」「舌」のように、よく一緒に使うShape Keyをグループにまとめて、チップ1つで絞り込めます。部位と違い、1つのShape Keyを複数のグループに入れられます。

- **作る**：グループのチップの右端の`＋`を押すと、グループをすぐに作り、「部位とグループ」ウィンドウでそのグループを開きます。名前の欄が選択された状態なので、そのまま名前を入力できます。検索欄に`Tare`などと入力してから押すと、名前が`Tare`、条件が`*Tare*`のグループになり、検索語を含むShape Keyがすべて入ります。`絞り込み`メニューの「『Tare』を含むShape Keyでグループを作る」も同じ動きです。
- **1つずつ入れる**：一覧の行を右クリックし、`グループに追加`から選びます。`新しいグループ…`を選ぶと、そのShape Keyを入れたグループを作って、同じようにウィンドウで開きます。
- **外す**：グループを選んでいる間、行の右クリックに「『グループ名』から外す」が出ます。
- **名前の変更・並べ替え・削除**：グループのチップを右クリックします。削除してもShape Key自体は変わりません。
- **細かく編集する**：チップの右クリックの`編集…`、または`設定`ページの`グループを編集`で「部位とグループ」ウィンドウのグループタブを開きます。左でグループを選び、右で名前と名前の条件を編集します。条件の下には顔メッシュのShape Keyがチェック付きで並び、条件を変えるとその場で結果が変わります。チェックを付け外しすると手動で追加・除外し、行の右端に「条件」「手動で追加」「手動で除外」と理由を表示します。`グループ内だけ`で該当するものだけに絞れます。一覧はグループに入っているShape Keyが先頭に並びます（チェックを付け外ししても、その場では行は動きません。グループや条件、検索を変えると並べ直します）。

グループは名前の条件（`*`を使うワイルドカード。`Eyelid_*`・`*Tare*`・`*_R`など、大文字・小文字は区別しません）と、手動で入れた名前・外した名前で決まります。手動で外した名前は、条件に一致していても表示しません。Shape Keyは名前で記録するため、顔メッシュのパスが違っても、同じ素体の別アバターで同じ名前のShape Keyにそのまま使えます。今の顔メッシュにない名前は表示しませんが、データには残ります。

グループは最初に作った時点で、アバター設定と同じフォルダの`ShapeGroups.asset`に保存します。グループの作成・変更はUndoで戻せます。

#### 別のアバターと共有する

`設定`ページの`Shape Keyグループ`で、このアバターが使うグループのファイルを選べます。別のアバターの`ShapeGroups.asset`を指定すると、同じグループを共有します。共有中は「他の◯個の設定でも使用中」と表示し、変更はすべてのアバターに反映されます。`複製してこのアバター専用にする`で、このアバター用のコピーに切り替えられます。

新しいアバターを`新規セットアップ`すると、Project内の既存のグループのうち、名前や条件の6割以上がこのアバターのShape Keyに一致するものを探します。見つかった場合は`複製して使う`・`共有して使う`・`使わない`から選べます。同じ素体の改変アバターなら、グループを作り直す必要はありません。

グループのタブ上部の`対象の素体`と`作者`は、この提案や`設定`ページに表示します。グループのファイルを配布するときの説明にも使えます。今のメッシュにない名前は件数を表示し、`このメッシュにない名前を削除`で整理できます。共有先のアバターで使っている名前の場合があるため、自動では削除しません。

### Default Faceを編集する

Default Faceは、手の形に割り当てがないときの顔で、**シーンのアバターの顔メッシュのBlendShapeの値**そのものです。素材一覧の先頭にある`Default Face`を選ぶと、表情と同じ画面で編集できます。値を変えると、シーンのアバターの顔メッシュに直接書き込み、RimeEmoの設定にも同時に反映します。Undoでまとめて戻せます。シーン上の顔・サムネイル・アップロード後のどれでも同じ顔になり、元FXのリップシンクなどもその上でそのまま動きます。

- `シーンの表情を読み込む`：今シーンのアバターに表示されている顔を、Default Faceとして取り込みます。他のツールやアニメーションのプレビューでシーンの顔が変わったときに使います。シーンの顔とDefault Faceが違うときは、違うShape Keyの数を表示します。
- `アニメーションをシーンに書き出す…`：アバターによっては、FXの最初の状態などのアニメーションで顔の初期値を変えています。そのアニメーションを選ぶと、その顔（0秒の値）をシーンのアバターに書き込み、Default Faceにします。素材一覧の表情のほか、`ほかのアニメーションから選ぶ…`でこのアバターの他のアニメーションも選べます。アニメーションに含まれないShape Keyは今の値のままです。

Default Faceの編集には、上のAvatar欄にシーンのアバターを指定しておく必要があります。

## 動きを付ける

「動きを作る」は、左目・右目・眉・口・その他のトラックにキューを並べる編集画面です。新規作成も既存AnimationClipの読み込みも、この画面で編集します。

`＋ 新しい動き`で空のタイムラインを作ります。保存済みの動きや外部の動きは、素材一覧でダブルクリックするか`動きを編集`で開きます。元ClipのコピーをMotionSourcesに保存し、記録された顔の動きを部位別のキューへ振り分けます。同じ内容のコピーがすでにある場合は再利用し、開くたびにファイルを増やしません。元ファイルは変更しません。読み込みだけでは新しい出力.animを作りません。

- 再生ヘッドを分割したい時刻へ移動し、キューを選んで`分割`または`S`を押します。分割直後の動きは変わりません。
- Ctrl／Cmd＋クリックで複数選択できます。同じ再生位置をまたぐ、選択されたキューをまとめて分割します。
- 静的キューは点、動きキューは元ソース区間の帯として表示されます。動きそのものは全高、保持はレーン上段、移行は下段の帯です。中央のドラッグで表情キーを移動します。再生ヘッドは移動しません。
- 横位置は共通の時間軸で、保持の終端から移行が始まります。帯をクリックすると保持・移行の詳細を選べます。動きキューの端は元Clipの使用区間をトリミングします。境界中央のつまみと詳細欄の「保持（秒）」「移行（秒）」で配分を変更します。次のキューの開始時刻は固定され、間隔を変えるには次のキューを移動します。末尾は保持だけを調整します。
- 動きの速度は選択キューの詳細欄で変更します。後ろにキューがある場合、その開始時刻を越えない範囲で調整します。
- `複製`またはCtrl／Cmd＋Dで、同じ部位の末尾へ選択キューを複製します。Deleteで削除できます。
- キューの境界や再生ヘッドの近くでは位置がスナップします。`60fps`を有効にすると、それ以外の位置を1/60秒単位に揃えます。
- 表情素材を部位のレーンへドラッグして配置できます。動きの素材をドラッグすると、そのレーンの部位の動きだけを動きキューとして配置します。編集中の動きが置き換わることはありません。その部位の変化を含まない動きは配置しません。
- 選択キューの表情欄で素材を指定すると、その区間・その部位を静止した表情に置き換えます。現在配置しているコピーは「配置中:」付きで表示します。
- ホイールで拡大・縮小、Shift＋ホイールまたはトラックパッドの横スクロールで時間軸を移動します。
- 静的キーは、隣のキーと同じ時刻には移動できません（1/60秒以上離れます）。
- 取り込んだ動きのトリミングと保持は独立しています。取り込み時に見つかった静止区間も同じ保持として編集できます。古いStep遷移は開くと保持へ変換され、再生結果を維持します。

取り込んだ動きを編集用タイムラインで初めて開くと、部位ごとに0.2秒以上の停止区間を検出し、動きのある区間をキューに分け、静止区間は保持として扱います。値の切り替えや全体の長さを保つために必要な境界キーは残します。該当するShape Keyのカーブがない部位にはキューを作りません。静的な表情から動きを作る場合も、その表情に含まれる部位だけを配置します。保存済みの編集データを開く場合は、その分割や調整内容を保持します。

条件を変えて追加で分割するときは、対象のキューを選び、右側の`自動分割`を押します。候補の区間と境界をタイムラインに表示し、`適用`で分割します。複数選択に対応し、適用は1回のUndoで戻せます。候補の確認やキャンセルでは下書きを変更しません。

`最小停止（秒）`の初期値は0.2秒で、キューの再生速度を反映した時間です。`許容変化量`が0なら完全に静止した区間を対象にし、正の値ならその範囲内の微小な変化も分割対象にします。微小でも変化のある区間は、元の動きを保つためキューとして残します。同じ部位のすべてのShape Keyについて、キー間の補間と区間全体の変化量を確認します。候補の境界には元Clipのキー時刻を使います。元Clipのカーブと素材参照は保持します。

既存Clipのキーと重み付き補間は元データを保持し、必要な区間だけ切り出して出力します。顔以外のカーブ、オブジェクト参照、Animation Eventは元の時間位置で保持します。顔のキューを動かしてもこれらは移動しません。元Clipの長さは全体の最小再生時間として保持します。プレビューとキュー編集の対象は選択した顔メッシュのBlendShapeです。

表情素材は配置時のコピーを使います。元の表情を後から直しても、配置済みの動きには反映されません。静的モードへ移動しても動きの下書きと再生位置は保持されます。

`保存`で初回の.anim保存先を選び、次回から同じClipを更新します。キューの編集情報もMotionsに保存します。名前欄を変更して保存すると、.animとMotions内の編集情報のファイル名も変更します。別名保存は名前欄の横の`別名で保存`です。RimeEmoで作っていない既存の.animを保存先に選ぶと、顔のBlendShapeカーブが置き換わることを確認してから上書きします。新規作成・別データへの切り替え・閉じる操作では未保存の変更を確認します。

### 動画編集ソフトと同じ操作

タイムラインをクリックしてから、次のキーとマウス操作が使えます。動画編集ソフト（Premiere ProやDaVinci Resolveなど）とそろえています。

| 操作 | キー・マウス |
|---|---|
| 再生・一時停止 | Space |
| 1フレーム戻る／進む | ← / →（Shiftで10フレーム） |
| 前／次の切れ目へ | ↑ / ↓ |
| 先頭／末尾へ | Home / End |
| 再生位置を動かす | ルーラーをクリック・ドラッグ |
| 範囲選択 | キューのない所をドラッグ（Ctrl・Shiftで追加） |
| 範囲で選択 | Shift＋クリック（同じ部位のキューを、前にクリックしたものからまとめて） |
| 追加で選択 | Ctrl＋クリック |
| すべて選択／選択解除 | Ctrl＋A / Esc（キューのない所のクリックでも解除） |
| コピー／切り取り／貼り付け | Ctrl＋C / Ctrl＋X / Ctrl＋V（再生位置に貼り付け） |
| キューを1フレーム動かす | Alt＋← / →（Shiftで10フレーム） |
| 分割／複製／削除 | S / Ctrl＋D / Delete |
| スナップの切り替え | N（ツールバーの`スナップ`と同じ） |
| 拡大／縮小／全体表示 | = / - / \ |

- 貼り付けは再生位置に置きます。1つの部位からコピーしたキューは選択中の部位へ、複数の部位からコピーしたキューは同じ部位へ、間隔を保って貼り付けます。貼り付け先にキューがある場合は、その位置から上書きします。動きのキューは、その部位の動きを含まない部位には貼り付けません。
- ドラッグ中にキューの端や再生位置へ吸着すると、黄色い線で位置を示します。
- 再生中は、再生位置が画面の外に出ると表示が追いかけます。
- キューの端にマウスを乗せると左右の矢印、中央では移動のカーソルに変わります。
- 右クリックのメニューにも、コピー・切り取り・再生位置に貼り付けがあります。
- キューのない所をクリックしても、再生位置は動きません（選択の解除になります）。再生位置はルーラーで動かします。

### 動きから表情を取り出す

`この時刻の表情を取り出す`で、編集中の顔のBlendShapeを静止値として新規保存します。元の動きの下書きと再生位置は保持され、取り出した表情の編集は動きに影響しません。

## Gestureを割り当てる

左のレールの`Gesture`を開きます。ページは上から順に進めるだけで設定できます。

1. **手の形に割り当てる**：左手・右手それぞれの8つの手の形（0 Neutral〜7 ThumbsUp、番号はVRChatのGesture番号）に、素材一覧やProjectから表情・動きをドロップします。`×`で割り当てを外します。空欄の手の形はDefault Faceになります。素材一覧にないClipは自動で取り込んでから割り当てます。
2. **両手で違う形をしたとき**：`左手を優先`・`右手を優先`・`組み合わせごとに選ぶ`から選びます。優先する手がNeutralのときは、もう片方の手の表情を使います。新しくセットアップしたProjectは`左手を優先`、以前のProjectは`組み合わせごとに選ぶ`から始まります。
3. **結果を確認する**：縦が左手、横が右手の8×8の表で、全64通りの結果を色分けして表示します（左手・右手・両手の組み合わせ・個別に設定・未解決・Default Face）。セルをクリックすると、その組み合わせだけ個別に表情を選べます。個別に設定した組み合わせは表の下の一覧からも変更・解除できます。
4. **アバターへ適用**：`再生成して適用`を押します。`切替の補間（秒）`でGesture間の切替時間を設定します。

左右の手が決まった組み合わせのときだけ使う表情は、`両手の組み合わせ（上級）`で追加します。片手の割り当てより優先されます。編集中の動きが未保存の場合は、ページ上部の`動きを保存`で保存してから割り当てます。

`元FXから取り込む`は、ルートのAnyStateからClipへ直接遷移するGesture等値条件を取り込みます。複雑な条件は自動変換しないため、手動で割り当ててください。Clip一覧の既存Gesture表示も解析可能な条件の参考情報です。

## FX生成とアバターへの適用

RimeEmoが生成するFXは、Gestureの割り当てから作る**レイヤー1枚だけ**のAnimatorControllerです。元FXは複製も変更もしません。アバター自身のFX（Avatar DescriptorのFXや、他のツールがMAで重ねたもの）はそのまま残り、RimeEmoのレイヤーがその上に重なります。生成先は`RimeEmoData/Generated/<アバター名>-<ID>/RimeEmoFX.controller`の1つだけで、生成のたびに同じファイルを上書きします。各表情のClipもこのファイルの中に入るため、適用を繰り返してもファイルやフォルダは増えません。以前のバージョンが作った`Build`フォルダは、`設定`ページの`未使用データを整理`で片付けられます。

**RimeEmoのレイヤーが書き込むのは、割り当てた表情・動きのどれかがDefault Faceから変えるShape Keyだけです。** 元FXから取り込んだ表情は、Default Faceと同じ値のShape Keyを大量に含んでいることがあります（例：266個のうち変えているのは11個）。こうした値は書き込み対象に数えません。 それ以外のShape Key（リップシンクの`vrc.v_*`、まばたき、他のギミックなど）には触れないので、アバターのFXのまま動きます。書き込むShape Keyは64通りのどの組み合わせでも書き込み、その表情が使わないものはDefault Faceの値にするので、前のジェスチャーの表情が残ることはありません。未割り当ての組み合わせも同じくDefault Faceです。静的Clipに含まれる顔以外のカーブ（衣装の切り替えなど）は、そのまま生成するClipにも残ります。

元FXに「手の形で表情を変えるレイヤー」が残っていて、RimeEmoの表情が使わないShape Keyを動かしている場合は、手の形によって元の表情が混ざって見えることがあります。このときGestureページの`4. アバターへ適用`に、該当するShape Keyの数を表示します（一覧はツールチップ）。`元FXの手の表情を止める`をオンにすると、それらのShape KeyもRimeEmoが書き込み、元の手の表情を止めます。初期設定はオフで、元のFXをそのまま尊重します。手の形のレイヤーかどうかは、遷移の条件やBlend Treeの軸に`GestureLeft`・`GestureRight`（Weightを含む）を使っているかで判定し、対象は`読込元FX`です。

`再生成して適用`は生成後、アバター直下に専用の子オブジェクトを作り、**MA Merge Animator**（FX・Absolute・Append）を設定します。レイヤー優先度は100（アバター自身のFXより上）、Write Defaultsは「アバターに合わせる」で作成します。この2つは作成後にMA Merge Animator上で変えてもかまいません。次に適用するときも上書きしません。適用にはVRChat SDKとModular Avatarが必要です。操作後はSceneを保存してください。以前のバージョンで適用したアバター（Replace）は、次に適用するとAppendに切り替わります。

### 未反映の変更を知らせる

適用後に表情・動き・Gesture割り当て・切替時間・顔メッシュを変更すると、上部バーの適用ボタンが`変更を適用`に変わり、左のレールの`Gesture`に印が付きます。Gestureページの`4. アバターへ適用`にも同じ状態を表示します。`変更を適用`を押すと、どのページからでも再生成して適用します。割り当てに未解決などの問題がある場合は適用せず、理由を表示しているGestureページを開きます。動きの編集内容が未保存の場合は、先に保存するか確認します。編集を続けられるよう、Hierarchyの選択は変更しません（Gestureページの`再生成して適用`は、適用先の子オブジェクトを選択します）。

ボタンの表示は次の3通りです。

- `アバターに適用`：まだ一度も適用していません。
- `変更を適用`：前回の適用後に変更があります。
- `適用済み`：アバターには最新の内容が適用されています。押せません。

判定は、生成時に記録した入力（解決後の8×8の割り当て、割り当てた各Clipのカーブ・イベント、動きをコンパイルした結果、顔のShape Key）と現在の入力の比較です。変更しても同じ内容に戻した場合は`適用済み`に戻ります。以前のバージョンで適用したアバター（Replace）は、`変更を適用`と表示します。

別のMAが同じ顔のBlendShapeを操作する場合や、Gestureパラメーターの型が合わない場合は、画面に理由を表示して適用を止めます。`適用を解除`はRimeEmo専用の子オブジェクトを削除します。元のAvatar DescriptorのFX設定は変更しないため、その構成へ戻ります。適用・解除はUndoにも対応します。

## 保存先と再開

作業データはツール本体とは別の`Assets/RimeEmoData`に保存します。ツールを更新するために`Assets/rimerime/RimeEmo`を入れ替えても、作った表情や動きは消えません。以前のバージョンで作った設定（`Assets/rimerime/RimeEmo/Working`内）はそのまま使えます。新しいFX生成物と書き出しは`Assets/RimeEmoData/Generated`に保存します。

セットアップすると、アバター直下に`RimeEmo Settings`オブジェクトと設定参照用コンポーネントが追加されます。Sceneを保存しておけば、次回は`Avatar`欄にそのアバターを指定するだけで設定が読み込まれます。Prefabとして使う場合は、この子オブジェクトもPrefabへ保存してください。設定用オブジェクトには`EditorOnly`タグが付き、アップロード対象から除外されます。

既存の設定は、Avatarを指定した状態で`RimeEmoData/Working/<アバター名>/RimeEmoProject.asset`を上部のProject欄へ指定すると関連付けられます。その後、Sceneを保存してください。設定のないアバターに切り替えると編集欄は未設定に戻り、前のアバターの設定は引き継ぎません。編集中の動的アニメーションに変更がある場合は、切り替える前に保存を確認します。

コンポーネントは設定アセットへの参照を保存します。アバターを複製した場合は同じ設定を共有します。別々に編集したい場合は、複製したアバターで`新規セットアップ`してください。別のUnityプロジェクトへ移す際には、以下の作業フォルダー内のアセットも必要です。

- 編集素材：`RimeEmoData/Working/<アバター名>/Animations`
- 動的AnimationClip：`Working/<アバター名>/Animations`（編集・保存する通常の.anim）
- 動的編集情報：同じ作業フォルダーの`Motions`（部位別ブロック配置・補間・素材参照）
- 動き専用の表情コピー：同じ作業フォルダーの`MotionSources`
- 取り込んだ動きの編集用コピー：同じ作業フォルダーの`ImportedAnimations`（以前に取り込んだClip。開くとキューへ読み込み）
- Clip書き出し：`RimeEmoData/Generated/<作業フォルダー名>/Animations`
- FX：`RimeEmoData/Generated/<アバター名>-<Project識別子>/Build*`

Motions内の編集情報は、素材一覧の保存済みの動きを開くと再開できます。部位別の素材参照、トリミング範囲、速度、補間を保存します。

### 未使用データの整理

`設定`ページの`未使用データを整理`は、どの保存済みの動き・編集中の動き・割り当てからも使われていないMotionSources内のコピーと、最新ではなくSceneやPrefabからも参照されていない古いFX生成物（`Build*`フォルダー）を、確認のうえOSのゴミ箱へ移動します。

Default Face・部位分類・Gesture割り当てはProjectごとに保存します。アバターの階層やメッシュを変更しても、保存済みパスやDefault Faceは自動更新されません。

## 対応範囲と確認状況

動的生成とプレビューの対象は選択した顔メッシュのBlendShapeです。Material、Transform、表示切替、Animation Event、PhysBoneなどはプレビューで再現しません。既存Clipの読み込みでは顔以外のカーブやイベントを保存時に保持します。静的Clipも未編集のプロパティを保持します。

FX生成は通常のAnimatorControllerに対応します。AnimatorOverrideControllerは通常のControllerへ展開して指定してください。既存の複雑なGesture条件を完全自動で移植する機能はありません。Gesture切替にはUnity Animatorの割り込み可能な固定時間遷移を使います。

Unity 2022.3.22f1の一時プロジェクトでコンパイルと回帰チェックを実施しています。`Tools > RimeEmo > Run Core Checks`で再実行でき、成功時にはConsoleに`RimeEmo core checks passed.`と表示します。カーブ生成、ブロック操作、静的編集、Undo、プレビューの元データ隔離、Gesture解決、FX複製と再生成を検証します。

実アバターでの画面・描画の目視確認、MAの最終ビルド、VRChat内での動作は未検証です。
